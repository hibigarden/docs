# Colorschemes

Open **Settings → Appearance** and choose **System**, **Light**, or **Dark**. System follows your operating system's appearance. You can choose a different palette for light and dark mode.

Choose **hibsy** (inspired by notesy) for a dark charcoal palette with lavender accents and muted gold highlights.

## Obsidian themes

Install a theme from **Settings → Addon Manager → Obsidian community** or from a folder. It appears in **Installed**, where you can preview, apply, update, or remove it. Installation does not apply it. Turn on **Obsidian themes** to use its palettes, which appear under **Obsidian themes** in the light and dark colorscheme pickers.

Themes and CSS snippets work across folders. **Appearance → Obsidian themes** contains snippet switches, theme options, and suggestions from an open vault. Hibi keeps its own copies and does not change the vault's theme settings.

## Exported documentation

Choose a built-in palette before [exporting documentation](exporting.md) to keep those colors in the result. Custom addon palettes are not exported.
